# 🗺️ Point Map

How does points/miles accumulate and flow between different accounts?

## Earning

export const byName = (a, b) =>
  programs[a].name.localeCompare(programs[b].name);

export const earnEdges = Object.values(flows).filter(
  ({ kind }) => kind === "earn",
);

export const earnDestinationsOfType = (type) =>
  [...new Set(earnEdges.map(({ to }) => to))]
    .filter((id) => programs[id].type === type)
    .sort(byName);

export const earnSankeyNodes = [
  ...[...new Set(earnEdges.map(({ from }) => from))].sort(byName),
  ...earnDestinationsOfType("airline"),
  ...earnDestinationsOfType("hotel"),
  ...earnDestinationsOfType("bank"),
].map((id) => ({ id, name: programs[id].name }));

Each ribbon is one earning partnership, so a node's height is its partner count, not how much a route actually pays. Hover a ribbon to follow one route, or a program to see every route through it, each labeled with its rate.

Only one program earns per car rental. A flat per-rental award (500 miles) is not comparable to a per-dollar rate (2 Miles/$): on a long or expensive rental the per-dollar partners pay far more.

<SankeyChart
  nodes={earnSankeyNodes}
  gutter={160}
  links={earnEdges.map(({ from, to, rate }) => ({
    source: from,
    target: to,
    value: 1,
    label: rate ?? undefined,
  }))}
/>

export const earnRows = earnEdges.map((flow) => ({
  from: programs[flow.from].name,

  to: programs[flow.to].name,
  toUrl: programs[flow.to].url,
  rate: flow.rate ?? "",
  url: flow.url,

## Transfer

export const transfers = Object.values(flows).filter(
  ({ kind }) => kind === "transfer",
);

export const destinationsOfType = (type) =>
  [...new Set(transfers.map(({ to }) => to))]
    .filter((id) => programs[id].type === type)
    .sort(byName);

export const sankeyNodes = [
  ...[...new Set(transfers.map(({ from }) => from))].sort(byName),
  ...destinationsOfType("airline"),
  ...destinationsOfType("hotel"),
].map((id) => ({ id, name: programs[id].name }));

Each ribbon is one transfer partnership, so a node's height is its partner count, not the value of the points: there is no spend data behind these flows. Hover a ribbon to follow one route, or a program to see every route through it, each labeled with its transfer ratio.

<SankeyChart
  nodes={sankeyNodes}
  links={transfers.map(({ from, to, ratio }) => ({
    source: from,
    target: to,
    value: 1,
    label: ratio.join(":"),
  }))}
/>

export const transferRows = transfers.map((flow) => ({
  from: programs[flow.from].name,
  to: programs[flow.to].name,
  toUrl: programs[flow.to].url,
  ratio: flow.ratio,
  minimumTransfer: flow.minimumTransfer,
  notes: flow.notes ?? "",
}));
